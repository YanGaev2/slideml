# Арт-дирекция

Решите по порядку и запишите в `plan.md`:
1. **Настроение** — 3 слова о том, как презентация должна ощущаться («тёплая, честная, локальная»).
2. **Палитра** — фон, текст, один акцент, 1–2 нейтральных. Акцент только для главного на слайде.
3. **Шрифты** — заголовки и текст, не больше двух семейств.
4. **Фирменный приём** — одна повторяемая идея на 3 и больше слайдах. Примеры: один акцентный блок, который Morph перемещает к главному элементу; фото в одной тонировке; крупные числа одним шрифтом; одна диагональ или линия.
5. **Ритм** — чередуйте светлые слайды с тёмными или фото. Подряд не больше 3 одинаковых по фону.

## Три готовых пресета `<theme>`

Скопируйте пресет в `<theme>` из `starter.xml`, затем при необходимости поменяйте акцент.

**Тёплый редакционный** (еда, ритейл, локальный бизнес) — уже стоит в `starter.xml`:
```xml
<theme font="Manrope" heading="Unbounded SemiBold"
       dk1="#1E1A17" lt1="#F7F3EC" dk2="#6E655C" lt2="#E4DDD2"
       accent1="#C2410C" accent2="#1E1A17" accent3="#6E655C" accent4="#E4DDD2" accent5="#6E655C" accent6="#E4DDD2"/>
```

**Строгий швейцарский** (отчёты, B2B, финансы):
```xml
<theme font="Inter" heading="Inter SemiBold"
       dk1="#111111" lt1="#F4F3EF" dk2="#6B6A66" lt2="#D9D7D1"
       accent1="#FF4F12" accent2="#111111" accent3="#6B6A66" accent4="#D9D7D1" accent5="#6B6A66" accent6="#D9D7D1"/>
```

**Тёмный технологичный** (продукты, ИИ, стартапы):
```xml
<theme font="Manrope" heading="Unbounded"
       dk1="#0B1026" lt1="#F5F7FF" dk2="#8B93B8" lt2="#232B52"
       accent1="#3DF2D0" accent2="#7B5CFF" accent3="#8B93B8" accent4="#232B52" accent5="#8B93B8" accent6="#232B52"/>
```
Для тёмного пресета ставьте `bg="dk1"` и текст `color="lt1"`; для мягкого фона — большие эллипсы с `fill="radial(accent2/45 0%, accent2/0 70%)"` и `soft-edge="120"`.

## Правила
- Фон слайда — нейтральный цвет темы, не акцент. Акцентом заливайте только один главный элемент.
- Не используйте тени, свечение и градиенты на всём подряд. Один эффект — один смысл.
- Полупрозрачный текст (`/70`) только для второстепенного текста на тёмном фоне или фото.
