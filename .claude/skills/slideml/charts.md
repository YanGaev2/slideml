# Графики: форма по сообщению

Сначала сформулируйте, что график должен сказать. Потом выберите форму. Это метод Желязны.

| Сообщение | Форма SlideML | Архетип |
|---|---|---|
| Изменение во времени, до 12 точек | `chart type="column"` | A5 |
| Длинный ряд во времени, тренд | `chart type="line"` с `smooth="1"` | A5 |
| Сравнение объектов, рейтинг | `chart type="bar"` по убыванию | A6 |
| Часть целого, до 5 частей | плитки (A7) или `chart type="doughnut"` с `<center>` | A7 |
| Два значения одной метрики | не график, а «было → стало» | A4 |
| Одно число | не график, а крупное число | A3 |
| Много метрик | `table` | A8 |

## Оформление
- Неглавные столбцы — нейтральный цвет (`lt2`), главный — акцент: `colors="lt2, lt2, accent1"`.
- Подписи данных включайте (`labels="1"`) и добавляйте единицу через `format`, например `format="0.0&quot; млн&quot;"`.
- Подписи только у важных точек: атрибут серии `label-points="2"`.
- Сетку и линию оси убирайте, если есть подписи данных: `axis-color="none"`.
- Пояснения ставьте внутри `<chart>` по данным, а не отдельными текстами по пикселям:
  - `<note at="Июнь">+68 % к апрелю</note>` — выноска к точке;
  - `<ref value="96" label="среднее 96"/>` — линия уровня;
  - `<band from="H6" to="H7"/>` — подсветка периода (например, месяц запуска);
  - `<center sub="доля">31%</center>` — текст в центре кольца.
- Заголовок слайда говорит вывод, которого нет в столбцах: причину, сравнение, следствие.
- На слайде один график. Рядом — итог или причина, а не второй график.
