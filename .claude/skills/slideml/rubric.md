# Ревью по шкале

`RESULT: PASS` от `check.py` требует файл `examples/<имя>/review.json` с двумя и больше дизайн-проходами. Последний проход должен набрать не меньше 16 из 20 и не иметь нулей.

## Шкала: 10 критериев, по 0, 1 или 2 балла

| # | Критерий | 2 балла, если | Как проверить без картинки |
|---|---|---|---|
| 1 | Ответ первым | главный вывод на слайде 1 или 2 | сравните текст слайда 1 с ВЫВОДОМ в `plan.md` |
| 2 | Логика заголовков | заголовки подряд пересказывают презентацию | выпишите заголовки из `deck.xml` одной строкой |
| 3 | Заголовки-выводы | каждый заголовок — предложение с глаголом и числом | у каждого заголовка есть глагол и цифра |
| 4 | Числа с базой | у каждого числа есть база или «нет данных» | каждое число из `deck.xml` есть в таблице чисел `plan.md` |
| 5 | Аудитория | есть ответы на вопросы аудитории и финальная просьба или решение | в таблице вопросов нет пустых ответов |
| 6 | Правильный график | форма соответствует сообщению по `charts.md` | тип `<chart>` против таблицы в `charts.md` |
| 7 | Разнообразие | 4 и больше архетипов, соседние разные, есть тёмный слайд или фото | строка `deck:` в отчёте `check.py` |
| 8 | Один фокус | на каждом слайде есть явный главный элемент, нет пустой полосы | раздел `DESIGN REPORT` в выводе `check.py` |
| 9 | Образ и приём | каждое ключевое число показано приёмом из `visuals.md` или графиком; есть фото или осмысленный фон; нет иконок-заглушек | комментарии `<!-- A· V· -->`; нет `lint: … only text` и `lint: … icon` |
| 10 | Тест взгляда | пересказ каждого слайда за 5 секунд совпадает с планом | раздел «свежий зритель» ниже |

## Как сделать один дизайн-проход
1. Для каждого слайда запишите:
   - пересказ своими словами (одно предложение);
   - совпадает ли пересказ с заголовком в `plan.md`;
   - что глаз видит первым;
   - самое слабое место и правку.
2. Поставьте баллы по 10 критериям.
3. Исправьте `deck.xml`: минимум одна правка на каждом слайде с баллом ниже 2 и на самом слабом слайде.
4. Запустите `check.py`.
5. Добавьте проход в `review.json`.

Если вы поставили 2 по всем критериям в первом проходе, ревью недействительно. Найдите хотя бы одну правку на каждый слайд.

## Три узких взгляда (делайте по очереди)
1. **История:** понятна ли презентация по одним заголовкам?
2. **Данные:** есть ли число, которое зритель поймёт иначе (месяц вместо квартала, % без базы)?
3. **Визуал:** на каждом слайде один фокус, нет пустой четверти, нет заглушек?

## Свежий зритель
- Если можете запустить отдельного агента, дайте ему только картинки `slideN.png`, без плана. Попросите пересказать каждый слайд одним предложением.
- Если не можете, не открывайте план. Посмотрите только картинки или раздел `DESIGN REPORT` и запишите пересказ. Потом сверьте его с планом. Каждое расхождение — правка.

## Формат `review.json`

```json
{
  "passes": [
    {
      "scores": {"1": 2, "2": 1, "3": 1, "4": 2, "5": 1, "6": 2, "7": 2, "8": 1, "9": 1, "10": 1},
      "weakest": "слайд 3: два одинаковых блока, главное спрятано в подписи",
      "changes": ["слайд 3: переделал в A4 «было → стало»", "слайд 1: добавил фото и затемнение"]
    },
    {
      "scores": {"1": 2, "2": 2, "3": 2, "4": 2, "5": 2, "6": 2, "7": 2, "8": 2, "9": 1, "10": 2},
      "weakest": "слайд 4: фото слишком тёмное",
      "changes": ["слайд 4: затемнение 60 % вместо 90 %"]
    }
  ]
}
```
